# Peak Dive desktop releases

Download the Peak Dive desktop app for Mac and Windows.

- **Mac (Apple silicon):** [Peak-Dive-arm64.dmg](https://github.com/moritzwesemann/peak-desktop-releases/releases/latest/download/Peak-Dive-arm64.dmg)
- **Mac (Intel):** [Peak-Dive-x64.dmg](https://github.com/moritzwesemann/peak-desktop-releases/releases/latest/download/Peak-Dive-x64.dmg)
- **Windows:** [Peak-Dive-Setup.exe](https://github.com/moritzwesemann/peak-desktop-releases/releases/latest/download/Peak-Dive-Setup.exe)

The app loads [peakdiveapp.com](https://peakdiveapp.com) and updates itself from the releases here.
Source code lives in the private Peak repository; this repository only hosts the installers.
